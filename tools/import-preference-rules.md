# Import reviewed preference rules

`~/bin/import-foodbank-preference-rules` imports reviewed JSON generated by the
Rules Sheet into the client.

In the Sheet, generate the JSON, inspect the expanded **Generated Rules JSON**
tab, and choose **Foodbank rules → Copy reviewed JSON**. Then run:

```sh
import-foodbank-preference-rules
```

The helper rejects malformed or structurally invalid JSON before it changes the
client. It writes the configuration atomically, formats it, and runs the
configuration test. If formatting or the test fails, it restores the prior
configuration unchanged.

You can pass a reviewed JSON file instead of using the clipboard:

```sh
import-foodbank-preference-rules /path/to/reviewed-preference-rules.json
```

Review the resulting diff, run `npm run check`, and release the client normally.
