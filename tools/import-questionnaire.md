# Import a reviewed questionnaire

`~/bin/import-foodbank-questionnaire` imports the reviewed JSON generated by the
**Generated Questionnaire JSON** Sheet tab into the client. In the Sheet, review
the generated JSON and choose **Foodbank questionnaire → Copy reviewed JSON**;
the browser copy action then puts it on the Mac clipboard.

Then run `import-foodbank-questionnaire`.

Or save the reviewed JSON to a file and pass its path:

```sh
import-foodbank-questionnaire /path/to/reviewed-questionnaire.json
```

The helper rejects malformed JSON and a previously released answer key whose
stored answer type has changed. It records genuinely new dynamic answer keys in
the append-only ledger, formats the two files, and runs the referral-form test.
If importing or that test fails, it restores both files unchanged.

Review the resulting diff, run `npm run check`, and release the client normally.
The Sheet is not live configuration: a questionnaire only changes for referrers
when the reviewed client release is deployed.
