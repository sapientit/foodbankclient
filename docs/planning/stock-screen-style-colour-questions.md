# Stock screen style and colour questions

This compares the Stock screen reference on page 8 of `Images and prompts5.docx` with the current `/stock` screen. It deliberately excludes functionality, data and controls that are not present in both versions.

## Shared application frame

- Should I enlarge the Food Bank wordmark in the signed-in header to match the more prominent reference lock-up?
  A: yes (this is the common header so applies to all screens)
- Should the active `Stock` main-navigation item gain the reference's pale-blue filled tile as well as its blue underline, rather than using the underline alone?
  A: yes (applies to all screens)
- Should the signed-in screen include the small footer shown in the reference (`© 2026 Food Bank`, `Helping our community`, and the right-aligned links), or is its absence intentional?
  A: no

## Stock heading

- Should the Stock heading sit in a distinct, full-width pale-blue banner as in the reference, instead of beginning directly on the pale-blue page surface?
  A: yes - and this style is true on all screens other than the dashboard.
- Should the heading icon use the reference treatment: a pale-blue circle with a blue outlined box, rather than the current solid-blue circle with a white box?
  A: no
- Should the `Stock` title be the reference's dark navy, rather than the current category-blue?
  A: yes
- Should the heading be more compact vertically, with the smaller title and closer icon/text proportions shown in the reference?
  A: yes

## Filters

- Should the filters sit inside one white, rounded, lightly bordered panel, instead of the current transparent line between blue horizontal rules?
  A: yes
- Should the current visible `Shelf` and `Stock level` labels be removed so that the controls look like the reference's compact, self-contained filter fields? This would reverse the current written screen requirement that those labels are inline.
  A: yes
- Should the filter panel have the reference's larger white gap below it before the results table?
  A: yes

## Stock table

- Should the results table be enclosed in a white rounded card with the reference's subtle border/shadow, rather than standing directly on the screen background?
  A: yes
- Should the table heading use the reference's lighter blue-grey fill and lose or soften the current strong dark-blue rule beneath it?
  A: yes
- Should the row dividers be made much paler to match the reference's quieter table grid?
  A; yes
- Should the table become noticeably more compact — especially smaller column-heading/body text and shorter rows — to match the reference's denser desktop list?
  A: yes
- Should the table's outer edge, corner rounding and page selector be styled as one contained results panel, rather than leaving the table and any later controls visually separate?
  A: yes
